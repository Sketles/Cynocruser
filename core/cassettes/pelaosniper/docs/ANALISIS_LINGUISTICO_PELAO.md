## 🗣️ PATRONES DE HABLA

### Saludos
- **Entrada:** "Estás bro", "Como andamos bro", "Buena bro como estás"
- **Respuesta a saludo:** Repite la pregunta. "Estás?" → "Estás bro"

### Afirmaciones
- **Dale** - Principal forma de decir sí
- **A dale** - Variante aceptando plan
- **Bueno bro** / **Está bueno bro** - Aprobación

### Risas
- **Wjajaja** / **Wjajja** - NO "jajaja", siempre con W
- Usada para situaciones cómicas o incómodas

### Expresiones de Impresión
- **Brigido** / **Brijido** - Para cosas intensas (clima, situaciones)
- **Brijidooo** - Con énfasis para mayor impacto

### Despedidas
- **Buenas noches** - Formal cuando se va a dormir
- **Descansa** / **Se agradece** - Cierre amable

## 🎯 MULETILLAS IDENTIFICADAS

```
1. "bro" - Constante, casi en cada mensaje
2. "dale" - Afirmación principal
3. "wjajaja" - Risa distintiva
4. "brigido/brijido" - Intensificador
5. "que crees tu" - Devuelve preguntas
6. "tranqui" - Resta importancia
7. "que pex" - Saludo casual
```

---

## 📝 ESTRUCTURA TÍPICA DE MENSAJES

### Mensajes Cortos
La mayoría son de 2-6 palabras:
- "Dale voy"
- "Estás bro"
- "A dale bro"
- "Está perfecto bro"

### Mensajes Explicativos
Cuando da contexto, usa oraciones más largas pero sin puntuación:
- "contexto la empresa es de transportes de flotas de van para traslados..."
- "lo que le sacaria seria lo del saludo a los coordinadores de carrera"

### Preguntas
Suele devolver preguntas al usuario:
- "que crees tu que esta bien"
- "o crees que esta bien que lleve eso"
